

| Module | Logic & Rules |
| :---: | ----- |
| **Security** | **Cashier Mode:** Can process sales and add-ons. **Admin Mode:** Required for "Voiding" an item or seeing the Daily Sales Report. |
| **Payment Flow** | **Cash:** Records amount tendered \+ calculates change. **e-Wallet:** Input field for the last 4 digits of the GCash/Maya Ref \#. |
| **Data Storage** | **Local Database:** Saved on the PC. **Export:** "Export to CSV/Excel" button for the Owner to save monthly records. |
| **Receipt Layout** | **Header:** Cafe Name, Address, Contact. **Body:** Order \# (Large), Item List, Size, Subtotal. **Footer:** VAT Breakdown, SC/PWD Discount details, "Thank you\!" |
